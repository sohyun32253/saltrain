# 🧂 SALTRAIN Project (Team)

## 📆 프로젝트 기간
2024.07.18 ~ 2024.08.16 (1개월)

---

## 📝 프로젝트 개요
SALTRAIN 브랜드 웹사이트를 리뉴얼하여  
**동적 요소 기반 상호작용**과 **브랜드 아이덴티티 강화**에 중점을 두었습니다.  

기존 웹사이트의 아쉬운 점:  
- 브랜드 USP(차별점) 전달 부족  
- 사용자 참여를 유도하는 상호작용 요소 부족  
- 정보 구조가 단순하지 않아 UX 저하  

개선 방향:  
- 동적 UI 요소를 활용하여 **흥미와 몰입감 강화**  
- 브랜드 이점 강조 및 지속 노출로 **구매욕구 자극**  
- **반응형 레이아웃**과 단순화된 정보 구조로 UX 개선  

---

## 🛠 기술 스택
- **Frontend**: HTML5, CSS3, JavaScript, Vue3, Vuetify, Vite, Vue CLI  
- **Design Tool**: Figma, Illustrator  
- **Collaboration**: GitHub

## ✍️ 회고
Vue.js 학습 후 바로 진행한 팀 프로젝트였기에 초반에는 심리적 부담이 컸습니다.  
그러나 팀원들과의 **의견 조율 및 협업**을 통해 문제를 해결해 나갔고,  
특히 **기존 HTML 코드를 Vue.js로 전환**하는 과정을 통해 Vue 프레임워크 이해도를 높일 수 있었습니다.  

또한 GitHub를 활용한 코드 공유/파일 관리, 정기 회의를 통한 일정 관리 등  
기본적인 **개발 협업 프로세스**를 경험할 수 있었습니다.  

특히 전직 디자이너 출신 팀원과 함께 **레퍼런스를 찾고, 컨셉을 부여하며, 디자인을 완성해 나가는 과정**에서  
많은 의견을 주고받으며 프로젝트를 점차 업그레이드할 수 있었고,  
그 과정 자체가 매우 의미 있고 즐거운 경험이었습니다.  

> 추후에는 Vue Router를 활용한 라우팅 및 Firebase 연동을 추가하여  
> 더 완성도 있는 프로젝트로 발전시킬 계획입니다.
